Omni

Connect this app to your OMNI server.

Using the OMNI AI app on your computer? Open it, choose Phone → Connect your phone, turn it on, then type the address it shows here. It will also show a 6-digit code to enter once.

Connect only to a server you run yourself. If it can be reached from the internet, turn on sign-in there (OMNI_REQUIRE_LOGIN=1) and use https. Your data stays on that server; this app only shows it.
