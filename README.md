# Omni-AI

A self-hosted AI workspace that keeps your chats, tasks, notes, files, and automations in one place on your own computer.

## What it includes

- Streaming chat with branching and citations
- Agents with approvals
- A knowledge base with search
- Calendar and web research
- A code editor
- Document and slide export
- Automations
- Connections to GitHub, Notion, Todoist, Slack, Discord, and Google

## AI provider

All AI goes through OpenRouter using your own API key.
